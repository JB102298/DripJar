The Sprint 1 database changes were previously applied manually through raw SQL because Drizzle Kit could not perform the rename interactively. We now need a committed, version-controlled migration that can reproduce the current schema in another environment.

Required schema changes:

1. Rename:

   users.reset_token

   to:

   users.reset_token_hash

2. Preserve the existing reset-token values during the rename.

3. Keep the existing reset-token expiration column unchanged unless the committed schema uses a different intentional name.

   - id
   - userId
   - tokenHash
   - userAgent, nullable
   - ipAddress, nullable
   - expiresAt
   - revokedAt, nullable
   - createdAt
   - lastUsedAt, nullable

5. Include all intended:

   - primary keys
   - foreign keys
   - unique constraints
   - indexes
   - defaults
   - delete behavior

Before making changes:

1. Inspect the current database schema.
2. Inspect the current Drizzle schema.

   - an older pre-Sprint-1 database

Then implement the migration.

MIGRATION REQUIREMENTS

- Store the migration in the repository.
- Use the project’s normal migration naming and journal format.
- Do not rely only on a command previously run manually.
- Do not generate destructive DROP TABLE or DROP COLUMN statements.
- Do not copy reset-token values into a new empty column and then discard the original.
- Preserve all current rows.
- Use conditional SQL only where appropriate and supported.
- If the migration system expects migrations to run exactly once, preserve that model rather than hiding errors broadly.
- Do not use blanket exception handling that could conceal a real migration failure.

CURRENT DATABASE HANDLING

Because the live development database may already have:

- reset_token_hash
- refresh_sessions

do not blindly rerun incompatible SQL.

Use a safe reconciliation method, such as:

- recording the migration as applied only after verifying that the current schema exactly matches it, or
- making the migration narrowly state-aware without suppressing unrelated errors.

Explain which method was chosen and why.
